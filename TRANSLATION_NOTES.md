# Translation notes

Nintendo’s official European GameCube localisation provides the wording and tone wherever a suitable counterpart exists. New English covers 64DD-only material and passages whose meaning differs in the remake. Original Japanese voices are retained.

Percentages count source entries, not words, screen pages or play time. “Nintendo-based” includes unchanged wording and adaptations; it does not mean an identical script or game. A reference used only to compare a changed monument does not count as imported English. The five principal Nintendo-based totals match the project comparison table; additional voiced material is shown separately.

“Unchanged” allows whitespace, line wrapping, subtitle pagination, joining adjacent opening cues and restoration of original icon artwork. “Adapted” includes all other wording differences, even punctuation or capitalisation; not every adaptation was caused by space limits. The supplied European reference was labelled 60 Hz + Undub; it was not independently verified against an untouched retail image.

## Review and feedback

The project owner reports that the English translation was reviewed by a native English speaker who works as a copywriter, with no notes returned. This is an English-language review; it is not a claim of independent verification of every Japanese source passage or every possible game state. Translation, timing and contextual feedback is welcome; please include the entry ID where possible.

## Independent project

This localisation is independently developed. It does not use Ozidual’s translation, patch or code, and is not intended to replace or supersede that project. Ozidual described the earlier project as mothballed in [May 2026](https://krikzz.com/forum/index.php?topic=5882.60). Public community documentation is credited where referenced.
